First public alpha of MP1 Configuration Studio, application build **1.39.0.14**, for an existing **MediaPortal 1.39** installation.

- Modern grouped navigation with icons, searchable settings and navigation history.
- Light/dark themes, 100–175% sizing and collapsible help.
- More readable tabs, lists and hover states; buffered native page presentation.
- Original configuration pages and save handlers retained. Original Configuration.exe and DLLs are not replaced.

Validation: **95/95 x64 + 95/95 x86 fixture checks**, **27/27 native core checks**, **61/61 sections**, **57/57 saving sections**, **68/68 field round trips**, five plugin forms, and the original OK-save/restart cycle.

**Tested native runtime: MP1 1.39 x64.** Native x86, all plugins and hardware workflows still need wider testing. This is an unsigned alpha, not a stable release. Back up configuration before testing.

Download the ZIP, extract it completely, and run **MP1ConfigurationStudio.exe**. Windows may request administrator approval to add the Studio files beside the installed configurator. See README and VALIDATION in the package/repository for instructions and limits. No MediaPortal runtime or user configuration is included.
