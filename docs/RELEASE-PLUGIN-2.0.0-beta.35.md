# MP1 Configuration Studio plugin 2.0.0-beta.35

**Status:** Preview aligned with desktop Studio beta.35. Unsigned preview.

## New

- Selection dialogs instead of free-text entry for discoverable values:
  - installed skins (`skin` folder)
  - installed languages (`language\strings_*.xml`)
  - installed fonts
  - Blu-ray regions A/B/C
  - common audio/subtitle language codes
  - all schema combo fields
- The current value is shown first and preselected.
- Rows with a selection list are marked `▸`.
- Left/Right cycles the list; OK/Enter opens the full dialog.

## Verified

- Skin selection from 10 installed skins, Titan selected and saved, then restored to Backdrop.
- Language selection from installed language files (7 pages).
- Save, ZIP backup, back to home, MediaPortal stays running.

## Limits

- Unsigned.
- Changes require a MediaPortal restart.
