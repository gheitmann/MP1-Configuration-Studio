# MP1 Configuration Studio plugin 2.0.0-beta.62

- The plugin now follows the MediaPortal UI culture for **French and Dutch** as well: the translated settings schema (labels, help texts, option lists, group and section titles) and the plugin's own status and dialog strings render in all four languages (German, English, French, Dutch).
- Shared translation tables are compiled into the plugin; unresolved strings fall back to English.
