# MP1 Configuration Studio plugin 2.0.0-beta.34

## Fixed

- Skin fonts now use `font22` and `font14`, which exist in Backdrop and Titan.
- Stronger focused/unfocused text contrast keeps the selection visible in skins without the Backdrop list-focus textures.

- Own focus model for Up/Down/Left/Right/OK/Back.
- Immediate label refresh after value changes.
- Direct atomic `MediaPortal.xml` writes with ZIP backup; no shared settings-cache rewrite.
- Restart required after saving.
